## Conceptos y explicacion 
- Polimorfismo: Lo uso con el impuesto,ya que la prodcutora aplica el impuesto sobre el precio de las entradas, entonces lo define el objeto productora, y lo usa entradas usando productora.impuesto()
- Listas: uso listas para el historial de bandas que vio un asistente, para las bandas que asisten a los shows, y para los asistentes que van al show. Ademas de listas, uso varias funciones para trabajar sobre ellas para cumplir las consignas(Filter, sum, size, etc.)
- Clases y Herencia: Uso clases a lo largo de todo el ejercicio para evitar repetir logica. Esta, por ejemplo, la clase banda que heredan los distintos tipos de banda. 
- Self: Cuando tengo que llamar a un metodo dentro del mismo objeto/clase, use self mas de una vez, para evitar escribir el nombre.
- Clases abstractas: Las uso cuando los metodos cambian segun quien herede la clase. En banda lo uso, ya que deje varios metodos sin cuerpos, y lo defini mas adelante.
